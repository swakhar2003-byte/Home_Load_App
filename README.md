# Home Energy (Android অ্যাপ)

প্রতি ঘণ্টার অ্যালার্ম + লাইট/ফ্যান ON/OFF ইনপুট + রাতের অটো নিয়ম + CSV শেয়ার।

## APK বানানোর নিয়ম (ফ্রি, GitHub দিয়ে)
1. github.com-এ একটা নতুন repository বানান (Private হলেও চলবে)।
2. এই ফোল্ডারের সব ফাইল (`.github` ফোল্ডার সহ) repository-তে আপলোড করুন।
3. repository-র **Actions** ট্যাবে "Build APK" চলতে দিন (৫–১০ মিনিট)।
4. শেষ হলে সেই run খুলে নিচে **Artifacts → home-energy-apk** ডাউনলোড করুন, zip খুলে `app-debug.apk` ফোনে ইনস্টল করুন।
